# Security policy

Report a vulnerability privately through GitHub security advisories ("Report a vulnerability" on the Security tab).
Do not open a public issue. The full policy lives in the shared
[gamaware/.github](https://github.com/gamaware/.github/blob/main/SECURITY.md) repository.

This repository is an index of public portfolio repositories. It contains no account data, credentials or client
information. If you find anything that looks real, report it the same way.
